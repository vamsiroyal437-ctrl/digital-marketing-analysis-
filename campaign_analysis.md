# Campaign Analysis Notes

This repository contains a synthetic campaign dataset and a Python script that calculates CTR, conversion rate, CPC, CPA and ROAS. Run `python analyze_campaigns.py` to create the KPI CSV report.

Use the generated metrics to compare channels, identify high-ROAS campaigns and investigate low conversion rates. Metrics alone do not prove causality; consider audience, campaign objective, attribution window and sample size before making decisions.
